# User Story: Painel Admin — Results (/admin/results)

**ID:** 8.5
**Epic:** 8 - Feedback Loop & Inteligência de Resultados
**Status:** TODO
**Agent:** @sm (draft) → @dev (implement) → @qa (review)
**Depends on:** Story 8.1 (Schema), Story 8.3 (Métricas)

---

## Statement

As a SOL administrator,
I want a results dashboard at /admin/results,
so that I can monitor the overall performance of scripts generated by the platform.

---

## Context

Painel administrativo com visão consolidada de resultados de roteiros. Exibe distribuição de classificação, performance por nicho e por módulo de prompt, gap de execução e evolução temporal. Dados carregados via Server Components — sem real-time, sem gráficos no MVP.
