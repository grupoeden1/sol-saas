| Check | Result | Detalhes |
|-------|--------|----------|
| Revenue JOIN logic | WARN | JOIN `ct.amount = cp.credits` — padrão pré-existente de `admin.ts`. Funcional enquanto pacotes têm credits únicos. Risco: se dois pacotes compartilharem mesmo `credits`, infla receita. Backlog: adicionar `creditPackageId` FK em CreditTransaction |
| Tokens filtra `type='consumption'` | PASS | Query usa `WHERE type = 'consumption'` corretamente |
| Credits separa purchase vs consumption | PASS | CASE WHEN correto; adjustments excluídos intencionalmente |
| API cost usa pricing por modelo | PASS | Lookup em `API_PRICING` com fallback para Haiku |
| DATE_TRUNC timezone | PASS | `AT TIME ZONE 'America/Sao_Paulo'` em todas as queries |
| Messages secondary (com anexo) | PASS | Corrigido: usa COUNT de CreditTransaction com `hasAttachments=true` (1 tx ≈ 1 msg), não subquery correlacionada |
