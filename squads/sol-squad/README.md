# Sol Squad 🌞

Squad especializado na construção do **Sol** — SaaS de criação de ofertas com IA conversacional orquestrada por Kestra.

## Agents

| Agent                   | Role                | Foco                                         |
| ----------------------- | ------------------- | -------------------------------------------- |
| 👑 **@pm**              | Product Manager     | Roadmap, PRDs, priorização, coordenação      |
| 🏛️ **@architect**       | Solutions Architect | Arquitetura, Kestra flows, DB, APIs          |
| 🤖 **@ai-engineer**     | AI/ML Engineer      | LLMs, prompts, RAG, AI Gateway, custo        |
| 💻 **@fullstack-dev**   | Fullstack Developer | Next.js, tRPC, Stripe, chat UI               |
| ✍️ **@prompt-engineer** | Prompt Engineer     | System prompts, copy, estratégia de oferta   |
| 🎨 **@ui-ux-designer**  | UI/UX Designer      | Design system, UX do chat, identidade visual |
| ⚡ **@devops**          | DevOps              | Kestra Docker, deploy, CI/CD, monitoring     |
| 🔎 **@qa**              | Quality Assurance   | Testes E2E, validação de IA, mobile          |

## Workflow de Colaboração

```
@pm (define requisitos)
  → @architect (projeta solução)
    → @ai-engineer + @prompt-engineer (implementam IA)
    → @fullstack-dev (implementa app)
    → @ui-ux-designer (design da interface)
  → @devops (deploya e monitora)
  → @qa (testa tudo)
```

## Como Usar

Mencione o agente no chat para ativar seu contexto:

- `@pm` — para planejamento e priorização
- `@architect` — para decisões técnicas
- `@ai-engineer` — para implementação de IA
- `@fullstack-dev` — para código e integrações
- `@prompt-engineer` — para qualidade dos prompts
- `@ui-ux-designer` — para design
- `@devops` — para infra e deploy
- `@qa` — para testes e validação
